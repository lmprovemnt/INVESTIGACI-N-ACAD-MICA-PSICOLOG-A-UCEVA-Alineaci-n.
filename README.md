# Investigación Académica - Psicología UCEVA

## Alienación Tecnológica: Desconexión de la Realidad Material y del Cuerpo Humano

Proyecto web interactivo y multidisciplinar desarrollado para la presentación de la investigación académica en la **Unidad Central del Valle del Cauca (UCEVA)**, Facultad de Ciencias de la Salud / Programa de Psicología.

### Tecnologías Utilizadas
- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion** (Animaciones fluidas y transiciones editoriales)
- **Lenis** (Smooth scroll)
- **Lucide Icons**
- **React Router DOM**

---

### Scripts de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar build de producción
npm run preview
```
